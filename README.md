# Zahlenspiel

Ein kleines Konsolenspiel in Python: [z. B. Der Computer denkt sich eine Zahl 
zwischen 1 und 100 aus, und man muss sie erraten. Nach jedem Versuch gibt es einen 
Hinweis „zu hoch“ oder „zu niedrig“.]

## Was ich dabei gelernt habe
- Zufallszahlen mit dem Modul `random`
- Schleifen (`while`) und Bedingungen (`if` / `elif` / `else`)
- Benutzereingaben mit `input()` und Prüfung auf gültige Zahlen
- [weiteres, z. B. Versuche zählen]

## So startest du das Spiel
1. Python 3 installieren (python.org)
2. Datei herunterladen
3. Im Terminal ausführen:

    python [dateiname].py
